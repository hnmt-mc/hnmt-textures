# テクスチャの制作元と仕上げ

全72バリエーションを32×32・RGBA・二値透過に統一しています。
IDと既存ファイル名は変えていません。魚の元絵には組み込みimage_genを使用し、
縮小後に色数・輪郭・成魚と若魚の体格・模様を整えています。
手描きであるとは表記しません。魚（`make_fish_art.py`）・餌（`make_bait_art.py`）・料理と米・いくら・まな板（`make_food_art.py`）は、座標と配色を指定したピクセル描画で、スクリプトから作ります。イカは、上から見た形です。

## 魚の編集元

`fish.json`は32行×32列のインデックス形式です。`.`は透過、それ以外は`palette`の色です。
`make_fish_art.py`が、座標と配色の指定から`fish.json`を作ります（`make_fish_art.py`の次に`make_textures.py`を実行します）。
`make_textures.py`はこの編集元をそのままPNGへ書き出します。再生成に画像生成APIは要りません。

スロットの中で小さく見えても魚と分かるよう、体を枠いっぱいに取り、次のように描いています。
- 目は、白目3×3に黒い瞳2×2（小さい魚だけ2×2）。
- ひれは、体と違う色で大きく。
- 模様は、種の見分けになる所を強調（タイの青い斑点、サバの背の波模様、ハマチ・ブリ・カンパチの黄色い帯と、カンパチの目を通る黒い帯、サーモンの黒い斑点、マグロの黄色い小離鰭など）。
- 輪郭は青みのある灰色の1ピクセル。横幅は、輪郭を含めて32以内（超えると作成を止めます）。

## 料理・米・いくら・まな板

`make_food_art.py`が、座標と配色の指定から、32×32の絵を作ります。
皿や器を枠いっぱいに取り、1ピクセルの暗い輪郭で囲み、具の色を種類ごとにはっきり変えています。
刺身は、切り身を扇形に並べて、大根のつまと大葉とわさびを添えます。握りは、ネタの色と模様で見分けます（コハダとサバは、皮の青い帯。ウナギは、海苔の帯）。
丼は、朱塗りの器に、具を並べます。焼き物・煮物は、魚の身の形と焼き色・煮汁の色で見分けます。

## 釣竿の実物資料

メーカー公式の構造・握り・リール位置を参考にしています。
商品画像やロゴはパックへコピーしていません。
ブランド品の完全なレプリカではなく、ゲーム内の区分を読み取れるように描いています。

- 渓流: [DAIWA 小継 渓流 X](https://www.daiwa.com/jp/product/t72ir1t)、[SHIMANO 渓流テンカラ](https://fish.shimano.com/ja-JP/product/rod/keiryu/tenkara/a075f000045cf1bqau.html)
- 磯: [SHIMANO ホリデー イソ](https://fish.shimano.com/ja-JP/product/rod/isobouhatei/other/a075f00002ltl7gqaq.html)
- 船: [SHIMANO ライトゲーム BB](https://fish.shimano.com/ja-JP/product/rod/funehanyou/lightgame/a075f00003rgsqmqak.html)

渓流はリールなし、磯はスピニングリール、船は両軸リールです。
通常と投げた状態は同じ竿を描き、通常側だけに糸と針を追加します。

## 料理

刺身・握り・丼・焼き物・煮物・汁物で盛り付けを分けています。
白身は繊維と皮の色、サーモンは脂の筋、マグロは艶、うなぎは焼き目を描き分けています。
いくら丼は小粒のいくらを密に並べ、握りは小ぶりなシャリに長いネタを被せています。
料理のIDをJava側で有効にする変更は、この作業には含めていません。

## 米作り

`tools/make_rice_models.py` に、16×16の絵と座標をまとめています（バニラの作物に近い粗さ）。
田んぼの稲は、バニラの作物と同じ交差した板2枚です。苗は緑、実りは黄金色で、穂が垂れます。
苗と刈った稲は、薄い板1枚の平らなアイコンです。石臼は直方体4個（土台・上石・投入口・取っ手）です。
前の版は、直方体を最大158個使っていて、田んぼに並べると重かったため、作り直しました。

`tools/blockbench_rice.cjs` がBlockbench本体でモデルと埋め込みテクスチャを読み込み、
編集元・Javaモデル・PNG・プレビューを書き出します。`rice-preview.png` はそのプレビューを並べたものです。
7種類は同じカメラ設定で撮影し、一覧の余白も共通の範囲で切り出しています。
ゲーム内での表示を確認した画像ではありません。
